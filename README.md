# Virel Digital – Data Science Journey

# &#x20;Integrated Python Programming and Problem-Solving

### Overview

This project covers Python programming skills through practical exercises involving data structures, loops, conditional statements and functions.

The exercises demonstrate how different Python concepts can be combined to solve practical data analysis problems.

### Learning Objectives

- Understand and manipulate Python lists and dictionaries.
- Use `for` and `while` loops to process data.
- Apply conditional statements to make decisions.
- Create reusable functions for different operations.
- Combine Python concepts to perform structured data analysis.

### Practical Exercises

**Exercise 1: Basic List Analysis**

- Calculate total expenses.
- Determine average expenses.
- Identify the highest and lowest expenses.
- Count the number of expenses.

**Exercise 2: Employee Records**

- Store employee names and salaries in a dictionary.
- Use loops to display employee records.

**Exercise 3: Salary Filtering**

- Identify employees earning more than KSh 40,000 using conditional statements.

**Exercise 4: Marks Classification**

- Create a function to classify student marks into Excellent, Good, Average and Fail categories.

**Exercise 5: Integrated Employee Salary Analysis**

- Calculate total and average salaries.
- Identify the highest-paid and lowest-paid employees.
- Filter employees earning above KSh 40,000.
- Generate a complete employee salary report using functions, loops, dictionaries and conditions.
